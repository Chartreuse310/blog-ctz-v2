## #5 计划：文章列表页 tag 筛选 + 搜索

### 设计决策（已与你确认）
- **布局**：搜索框 + tag 横排，都在文章列表顶部
- **tag 排序**：按出现次数降序（同次数按字母/默认顺序）
- **tag 交互**：单选——点击选中筛选，点已选中的取消，点另一个切换
- **搜索 + tag 联动**：AND 逻辑（两者同时满足才显示）
- **无结果**：显示空状态提示 + "清除筛选"按钮
- **搜索范围**：title + excerpt + tags 子串匹配（不区分大小写）

### 技术约束（已调研确认）
- 只改一个文件：`PostList.vue`（不影响首页/about，它们没用该组件）
- 数据现成：`posts.data.mts` 已含 `tags: string[]` / `url` / `title` / `excerpt`，无需改 loader
- 纯客户端交互可行：`ref`/`computed` 在 VitePress 组件中已验证可用（Outline.vue 已在用）
- 无 hydration 风险：初始状态 = 全部文章（`selectedTag=null`, `query=''`），与 SSR 输出一致
- CSS 复用现有 `.post-tag` 样式作基础，新增选中态和搜索框样式

### 实现方案（PostList.vue 单文件改造）

**script 部分**：
```ts
import { ref, computed } from 'vue'
const selectedTag = ref<string | null>(null)
const query = ref('')

// tag 聚合：按出现次数降序
const allTags = computed(() => {
  const counts = new Map<string, number>()
  for (const p of posts) for (const t of p.tags || []) counts.set(t, (counts.get(t) || 0) + 1)
  return [...counts.entries()].sort((a, b) => b[1] - a[1]).map(([name, count]) => ({ name, count }))
})

// AND 筛选：tag + 搜索同时满足
const filteredPosts = computed(() => {
  const q = query.value.trim().toLowerCase()
  return (posts as Post[]).filter(p => {
    if (selectedTag.value && !(p.tags || []).includes(selectedTag.value)) return false
    if (q) {
      const hay = `${p.title} ${p.excerpt} ${(p.tags || []).join(' ')}`.toLowerCase()
      if (!hay.includes(q)) return false
    }
    return true
  })
})

const toggleTag = (tag: string) => { selectedTag.value = selectedTag.value === tag ? null : tag }
const clearFilters = () => { selectedTag.value = null; query.value = '' }
```

**template 部分**（在 `<ul>` 之前加筛选区）：
```html
<div class="filter-bar">
  <input class="search-input" v-model="query" placeholder="搜索文章..." />
  <div class="tag-filter-list">
    <button v-for="t in allTags" :key="t.name"
      :class="['post-tag', 'tag-filter-btn', { 'tag-filter-active': selectedTag === t.name }]"
      @click="toggleTag(t.name)">
      {{ t.name }} <span class="tag-count">{{ t.count }}</span>
    </button>
  </div>
</div>
```

列表区 `v-for="post in filteredPosts"`（替换原 `posts`），末尾加空状态：
```html
<div v-if="filteredPosts.length === 0" class="empty-state">
  没有匹配的文章
  <button class="clear-btn" @click="clearFilters">清除筛选</button>
</div>
```

文章项里的 tag span 也可点击触发筛选（增强便利），用 `<button>` 或 `@click`。

**CSS 部分**（新增，复用 brand 色变量）：
- `.filter-bar`：上方筛选区容器，底部 margin
- `.search-input`：搜索框，复用 VitePress 输入框风格（border + brand focus 态）
- `.tag-filter-list`：flex wrap 横排
- `.tag-filter-btn`：复用 `.post-tag` 基础 + `cursor:pointer` + hover 态
- `.tag-filter-active`：选中态（加深背景/反色，区分明显）
- `.tag-count`：计数，opacity 降低
- `.empty-state` + `.clear-btn`：空状态文字 + 清除按钮
- 响应式：窄屏搜索框占满宽度
